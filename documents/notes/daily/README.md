## Core mutation of the project

The source document describes a gradual change rather than a fixed concept:

**yōkai folklore → strange encounters → contemporary infrastructure → landscape as presence → memory archive → created mythology**

Recurring motifs recorded in the source include:

- Thresholds and transitions.
- Tunnels.
- Guides, especially Koba-san.
- Machines that feel animate, especially jihanki.
- Unexpected gifts.
- Artificial spirits such as Hatsune Miku and yōkai figures.
- Forest infrastructure such as the telephone booth.
- Aokigahara as a latent presence.
- Night walks.
- Everyday objects becoming mysterious.
- Hospitality.
- Small rituals: jihanki, cigarettes, cycling.
- The feeling of being inside a game.
- Shrines.

## Archive principle

These daily files are **source-derived notes**, not independent historical verification. Where the source marks something as a possible theme, it remains a possible theme here. Where the source leaves an encounter undefined, it remains undefined.
