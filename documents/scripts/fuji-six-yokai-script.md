# 富士山六体妖怪 — VIDEO SCRIPT

**Type:** Video script  
**Project:** Ilya Minin (Eli)  
**Audio:** Pos Eugene (friend)  
**Illustration / editing / script:** Ilya Minin (Eli)

富士山には、古くから「六大妖怪」が棲んでいる――。

山麓に残る口伝や古い記録をもとに、
富士山周辺に伝わるとされる六体の妖怪を紹介します。

・上葉山
・水好鬼
・須賀山
・江花師
・下津賀
・保外神

この動画は、日本の妖怪伝承や怪談番組へのオマージュとして制作した創作作品です。

※本動画に登場する妖怪・伝承・文献は創作です。
実在する民間伝承や歴史資料ではありません。
